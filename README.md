# Dafna Treatments

תוסף וורדפרס לאתר של דפנה סאיאס (dafna.shaharstudio.co.il): סוג תוכן "טיפול", פרטי העסק, שאלות ותשובות, והווידג'טים של האתר לאלמנטור (קטגוריה Dafna).

## עדכונים
האתר מציג "קיימת גרסה חדשה" במסך התוספים, לפי ה-release האחרון במאגר הזה. העדכון הוא תמיד לחיצה ידנית.

## הוצאת גרסה
1. מעלים את `Version:` ואת `DT_VER` ב-`dafna-treatments.php`, ומוסיפים שורה ל-`CHANGELOG.md`.
2. אורזים את התיקייה כ-**`dafna-treatments.zip`** (התיקייה `dafna-treatments/` בתוך ה-zip).
3. יוצרים release עם תג `vX.Y.Z` ומצרפים את `dafna-treatments.zip`.
